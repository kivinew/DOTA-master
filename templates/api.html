📖 API документация

DOTA_MASTER REST API — программный доступ к статистике

🌐 Базовый URL
{{ request.host_url.rstrip('/') }}/api

Все эндпоинты возвращают JSON. Ответы имеют формат {"status": "success", ...} или {"status": "error", "message": "..."}.

📡 Эндпоинты
GET /api/games
Все игры (последние 50), отсортированные по дате
{ "status": "success", "games": [ { "date": "2026-09-13T22:39:17", "hero": "Invoker", "role": "offlane", "result": "win", "kills": 12, "deaths": 5, "assists": 4, "game_mode": "Turbo Archon [4]" } ], "total": 43 }
GET /api/games/<hero>
Игры конкретного героя
GET /api/games/Invoker → { "status": "success", "hero": "Invoker", "games": [...], "total": 36 }
GET /api/stats
Общая статистика
GET /api/stats → { "stats": { "total_games": 43, "total_wins": 23, "total_losses": 20, "global_win_rate": 53.5, "avg_kd": 10.28, "by_hero": [...] } }
GET /api/hero/<hero>/stats
Статистика по герою
GET /api/hero/Invoker/stats → { "stats": { "hero": "Invoker", "games": 36, "wins": 22, "losses": 14, "win_rate": 61.1, "avg_kd": 11.67 } }
GET /api/hero/<hero>/analysis
Анализ стратегии (что отличает победы от поражений)
GET /api/errors
Игры с критическими ошибками
GET /api/fresh_matches
Сырые свежие матчи из OpenDota (до обработки)
📋 Параметры
<hero> — название героя (латиницей)
Примеры: Invoker, Naga Siren, Weaver, Anti-Mage, Lich
